# Entrada compatible de captura

La captura se integró a la web Traina y a la API Java. Ejecuta `Main.cmd` en la raíz de `Prototipo_hack` o `run.ps1` en esta carpeta; ambos abren el mismo flujo completo. La clase `apprentice.Main` redirige al lanzador principal.

Claude interpreta la pantalla y dirige la conversación. ElevenLabs solo sintetiza las respuestas de Claude. La captura, el dictado, la privacidad, el debrief, el mapa y las prácticas se controlan en el navegador. Consulta el README de la raíz para configuración y verificación.
